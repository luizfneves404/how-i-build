# Games

## “I want to make a 2D browser game”
- Phaser 4 (TypeScript)
- Use PixiJS only if you want rendering, not a full game framework.

## “I want fast 2D rendering on the web”
- PixiJS (TypeScript)

## “I want a simple Rust game loop”
- Macroquad (Rust)

## “I want a code-first Rust engine”
- Bevy (Rust)
    - Great architecture, less mature tooling.

## “I want a 3D browser game”
- PlayCanvas (TypeScript)

## “I want a normal indie engine”
- Godot (GDScript/C#)

## “I want the safest commercial default”
- Unity (C#)

## “I want high-end 3D / cinematic / AAA-style tooling”
- Unreal (C++/Blueprints)

## “I want simple 2D physics”
- Matter.js for TypeScript/web
- Rapier for Rust/native/web-WASM

## “I want custom GPU simulation or weird physics”
- raw wgpu (Rust) + compute shaders
- Bevy + compute shaders if you also want ECS/engine structure

## "I'm making a turn-based game"
- Add boardgame.io (TypeScript) to the stack
